---
title: "DNSSEC for internal ICANN domains"
---

*ICANN DNS Engineering* provides [DNS Security Extensions (DNSSEC)](https://www.icann.org/resources/pages/dnssec-qaa-2014-01-29-en) for the internal ICANN Domain Names portfolio using [OpenDNSSEC](https://www.opendnssec.org/). We currently don’t offer this service for external parties.

If you want to find more useful information about DNSSEC deployment, we suggest you to visit the following sites:

- [ISOC Deploy 360 DNSSEC](https://www.internetsociety.org/deploy360/dnssec/)
- List of a [few registrars](https://www.icann.org/resources/pages/deployment-2012-02-25-en) that provide DNSSEC
- [TLDs DNSSEC Report](http://stats.research.icann.org/dns/tld_report/) deployment status page
- IANA website about [DNSSEC information](https://www.iana.org/dnssec) for the Root Zone
  - IANA – Root Zone [Trust Anchor](https://www.iana.org/dnssec/files) (KSK)
  - IANA – Root Zone [KSK ceremonies](https://www.iana.org/dnssec/ceremonies)
- Information about the Root Zone [KSK Rollover](https://www.icann.org/resources/pages/ksk-rollover)
