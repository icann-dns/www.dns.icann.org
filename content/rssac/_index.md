The [Root Server System Advisory Committee](https://www.icann.org/groups/rssac) (RSSAC) advises the ICANN Board and ICANN community on matters relating to the operation, administration, security, and integrity of the root server system, as outlined in its [charter from the ICANN Bylaws](https://www.icann.org/en/groups/rssac/charter).

The RSSAC advisories, reports, and statements can be found in [its website](https://www.icann.org/groups/rssac/documents)

The following list, show some responses and comments from *ICANN DNS Engineering*, as the operator of the [ICANN Managed Root-Server (IMRS):](/imrs)

- RSSAC001: [ICANN Managed Root Server response for service expectations for Root-Servers Operators](rssac001-response/)
- RSSAC002: [ICANN Managed Root Server RSSAC Measurements](http://stats.dns.icann.org/rssac/)
- RSSAC024: [ICANN Managed Root Server response for Key Technical Elements of Potential Root-Server Operator](rssac024-response/)
- RSSAC037: ICANN Follows the [core Root Servers Principles](/imrs/root-servers-principles/) as specified in the [RSSAC037 original document](https://www.icann.org/en/system/files/files/rssac-037-15jun18-en.pdf)
