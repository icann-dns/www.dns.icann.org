The Root Server System Advisory Committee (RSSAC) published [RSSAC002](https://www.icann.org/en/system/files/files/rssac-002-measurements-root-06jun16-en.pdf) as an advisory to address **Measurements of the Root Server System.**

ICANN maintains [https://stats.dns.icann.org/rssac](http://stats.dns.icann.org/rssac/) with measurements back from June 2014 in YAML and PNG formats for several of its [services](/services), including [L-Root](/lroot/)
