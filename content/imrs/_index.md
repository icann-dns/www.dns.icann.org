ICANN Managed Root Server (**IMRS**) DNS system operates at

- Name label **L.ROOT-SERVERS.NET.**
- IPv4 address **199.7.83.42** from the ranges [**199.7.83.0/24**](/aboutus/nr/) and **[199.7.82.0/23](/aboutus/nr/)**
- IPv6 address **2001:500:9f::42** from the ranges [**2001:500:9f::/48**](/aboutus/nr/) and **[2001:500:9e::/47](/aboutus/nr/)**
- All these prefix ranges are announced from [**AS20144**](/aboutus/nr/).

The service uses the [Name Server Daemon (NSD)](https://www.nlnetlabs.nl/projects/nsd/) from [NLNetLabs](http://www.nlnetlabs.nl/), and [Knot DNS](https://www.knot-dns.cz/) from [CZ.NIC Labs](https://labs.nic.cz).
